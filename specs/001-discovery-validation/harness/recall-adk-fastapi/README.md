# Recall harness — codegraph route extraction vs. a FastAPI application's own route table

Produces the numbers in
[`findings/004-recall-against-authoritative-key.md`](../../findings/004-recall-against-authoritative-key.md).

Run `./run.sh` and compare the files it writes to `/tmp/f2a-recall/` against the
copies committed here. Zero model spend; nothing under `examples/` is modified.

| written to `/tmp/f2a-recall/` | committed copy to compare against |
|---|---|
| `answer-key.json` | [`answer-key.json`](./answer-key.json) |
| `results.json` | [`results/results.json`](./results/results.json) |
| `results-extras.json` | [`results/results-extras.json`](./results/results-extras.json) |

The two scored outputs moved from this directory's top level into `results/` on
2026-08-02, so that this harness matches every other one in the tree. The
answer key stays at the top level because it is committed *input* to scoring,
the same place `../contract-extraction/contract-key.json` sits.

## What each piece does

| File | Purpose |
|---|---|
| `run.sh` | End-to-end reproduction: copy, build, index, key, score. |
| `build_key.py` | Instantiates the ADK FastAPI application and reads `(method, path, handler)` off `app.routes` for five constructor configurations. This is the answer key, and its provenance is **machine-generated**. |
| `compare.py` | Scores the `route` nodes in a codegraph SQLite index against the key. Reports precision and recall separately, per scope, per filter, and per configuration, and enumerates every false negative and false positive individually. |
| `analyze_extras.py` | Two supplementary measurements against Python's own `ast` module as the authority: symbol-level recall for functions, and whether recorded docstrings are actually docstrings. |
| `answer-key.json` | The committed key. Regenerated by `build_key.py`. |
| `results/results.json`, `results/results-extras.json` | Committed outputs of the two scoring scripts. |
| `fixture-agents/probe_app/` | A minimal ADK agent. It exists only so the A2A and Gemini Enterprise configurations register their routes; without an agent directory those code paths register nothing. |

## Prerequisites

Node 20–24, `uv`, and Python 3.12. The `enterprise` configuration calls Google
Cloud metadata endpoints during application construction and takes about a
minute; it still succeeds without valid credentials, and the four other
configurations need no network at all.

## Answer key provenance

The key is read off the instantiated application's own route table, not
transcribed by hand (spec FR-008). `HEAD` entries that Starlette adds
automatically alongside every `GET` are dropped, because they are not separately
declared operations. Every other entry the framework will serve is kept,
including the ones no application source declares.
